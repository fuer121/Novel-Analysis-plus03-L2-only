# 《剑来》L1 召回历史评估

## 范围

该目录保留 2026-08-27 对《剑来》（`book_id: 143170`）前 50 章 L1 路由信号与 L2 事实召回的两轮本地评估脚本

- `l1_eval_50ch.py`：比较 L1 类别得分、L2 事实分布和实体召回
- `l1_eval_round2.py`：仅使用能在当章原文中校验的 L2 证据重新评估

## 定位

这些脚本是一次性历史评估工具，不是产品级执行入口，不纳入根 `scripts/`

脚本直读 `data/novel-chapters.sqlite` 的当前本地数据，后续重跑结果可能随索引数据变化，不应视为固定基线
