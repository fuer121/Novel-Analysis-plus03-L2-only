# Divorce Sample Migration Implementation Plan

**Goal:** 将《离婚后她惊艳了世界》的 250 个基础角色、279 条稳定阶段记录、279 张正式图片、R01-R22 审核历史和专项脚本迁入标准书籍工作区

## 正式基线

- `characters.json`：279 条稳定阶段记录，250 个基础角色
- `images/`：279 张 JPEG，与角色阶段逐条对应
- `222767_role_all.txt`：250 个基础角色聚合 279 张阶段图片
- `record-id-map.json`：本地角色记录与飞书记录映射，仅进入本地归档

R21、R22 和旧 README 中的 280 条描述已经过期。后续专项修订删除了错误标记为“楚锁锁-老年”的记录；其证据实际是第 350 至 351 章的临时抓伤，不构成老年稳定阶段

## 迁移分组

- `inputs/`：两份上层索引提示词、100 章原文抽样和图片上传提示词
- `final/`：279 条角色数据、279 张图片、角色画像导出与最终验证证据
- `runs/`：R01-R22、顾谨尧专项修订、楚锁锁专项修订及其他审核批次
- `scripts/active/`：当前仍可复用的角色构建、图片生成、角色画像导出和单图上传入口
- `archive/2026/legacy-scripts/`：已完成轮次的准备、生成、应用、同步和验证脚本
- `archive/2026/local-records/`：飞书记录、Dify 上传结果、签名 URL、文件令牌和内部服务记录

## 安全要求

- 1,167 个源文件迁移前生成完整 SHA-256 清单
- 114 份疑似敏感记录不得进入 Git
- 当前 279 条基线和旧 280 条审计记录必须明确区分
- 旧来源保留至 `2026-09-10`
- 不修改数据库、应用 API 或 Dify 工作流

## 完成条件

- 正式角色记录、图片和角色画像引用均为 279
- 基础角色数为 250
- 所有正式图片存在且哈希一致
- 每个源文件都有目标归属或明确的本地归档位置
- 活跃脚本使用书籍工作区路径并通过静态检查
- 目录契约、全量测试和构建通过
