# 角色形象生成规则

## 1. 适用边界

本规则用于从不同书籍的 L2 事实生成角色形象，复用证据、生成、质检和交付方法，不复用单本书的画风、服饰、种族和人物设定

删除影响：容易把《逆天邪神》的古风玄幻国漫风格误用到都市、科幻、西幻或其他题材

## 2. 书籍级配置

每本书全量生图前必须确认 L2 数据范围、截止章节、时代、世界观、文化体系、画风、写实程度、服饰、力量特效、种族、非人形态、标准构图和禁止元素

删除影响：会使整批图片出现时代、服饰、审美、力量效果和种族形态错配

## 3. 角色候选与证据

- 候选数量指角色主体数，不是阶段拆分后的最终图片数
- 组织、物品、境界、地名、泛称和无法稳定指向单一主体的称号不进入人物立绘队列
- 稳定的非人角色应保留，并按原文形态生成
- 身份、别称、性别、年龄或外观约龄、骨相、体型、服饰、标志和气质必须有可回查的 L2 事实或原文证据
- 无证据的属性标记未知，不为了补齐 Prompt 而猜测

删除影响：会把非角色对象当成人物，或将模型偏好和题材套路写成角色设定

## 4. 异名归并与阶段拆分

只合并有明确同人证据的本名、旧名、化名和唯一专属称号

只在时期或年龄节点明确、稳定外形差异成立且每个阶段都有独立证据时拆分形象，可使用「角色-少年」「角色-成年」「角色-本体」等名称

临时换装、情绪、战损、一次性易容和短暂力量异变不默认拆分

删除影响：可能合并不同角色，或把不同时期的脸部、体型和服饰拼成原文不存在的形象

## 5. 生图前准入检查

- 年龄或外观约龄与脸部、体型和着装一致
- 气质来自稳定原文特征，不把单一场景情绪当成永久气质
- 男女角色不使用同一脸型模板，通过眉骨、眼型、下颌、面部宽窄、肩颈比例和体格体现差异
- 每个角色至少有一项脸部或骨相锚点，以及一项体态、标志或气质锚点
- 未成年角色必须非性化且服饰完整
- 非人主体优先保留原文本体，不默认拟人

删除影响：会直接造成年龄错位、男女共脸、气质偏离、未成年性感化或非人形态错误

## 6. 小样先行

批量生图前必须选择覆盖不同性别、年龄、体型、阵营、服饰体系和非人主体的小样，验收画风、时代、服饰、骨相、年龄、形态和构图后才能全量生成

删除影响：全局 Prompt 中的错误会被成批放大，显著增加重绘数量和 API 成本

## 7. 图片输出格式

本项目后续所有生图、重绘和正式交付图片必须生成或转换为真实 JPEG 编码

- 文件扩展名统一使用 `.jpg`
- MIME 类型使用 `image/jpeg`
- 交付前根据文件内容校验编码，不得只把 PNG 改后缀为 `.jpg`
- JPEG 不支持透明通道，转换时必须先合成到任务指定背景，角色白底立绘使用纯白背景
- 历史 PNG 可作为评审或转换输入，但不能作为新任务的正式输出模板

删除影响：新脚本会继续沿用历史 PNG 惯例，或产生假 JPEG、黑色透明区域、上传映射混乱和 MIME 识别错误

## 8. 生图任务执行

- 每条任务保存稳定 ID、书籍、角色或阶段、Prompt 和目标 JPEG 文件名
- 批次范围不重叠，每批有独立结果日志
- 已成功且通过文件检查的任务不重复生成
- 限额、连接或安全审核失败时保留断点和失败原因，只重跑失败项
- API Key 不得写入 Prompt、JSONL、日志或交付文件

删除影响：中断后无法续跑，并可能重复消耗额度、覆盖正式图片或泄露凭据

## 9. 真实看图质检

不得根据 Prompt 推定图片符合要求，必须查看实际图片并检查：

- 真实 JPEG 编码、可解码、非空白、非全黑和目标画幅比例
- 单一目标主体，无多人拼图、重复人物和无关对象
- 性别、年龄、骨相、体型、服饰、气质和标志特征与证据一致
- 非人角色未被错误拟人，人形角色未被无证据异化
- 构图、背景、裁切、文字和水印符合书籍级配置
- 角色库不存在大面积共脸，男女、年龄层和个体特征可视区分

每张正式图应记录当前图片与原文的匹配度，至少覆盖年龄阶段、性别骨相与体态、标志特征、时代服饰、角色气质和立绘可用性

删除影响：无脸、多人、现代化、共脸、年龄错误、编码错误和非人误拟人会在未被发现时进入正式交付

## 10. 硬错重绘

性别或年龄错误、非人形态错误、无脸或严重裁切、多人、时代风格错误、文字水印和关键标志与原文相反必须重绘

重绘 Prompt 应针对实际问题改写，不能只增加「请修正」，重绘后必须重新看图、评分和验证 JPEG 编码

删除影响：会把「已重新生成」误当成「已修复」，使硬错继续留在最终形象库

## 11. 多维表格交付

- 保存书籍、角色或阶段、本地 JPEG、远端 `record_id` 和附件之间的稳定映射
- 附件使用附件专用上传方式，不当作普通文本值写入
- 重绘替换同时校验真实 JPEG 编码、文件大小或哈希，不只比较文件名
- 写入后从远端读回，确认记录数正确、每条记录恰好一个最终附件、缺失为 0、重复为 0，匹配度对应最终图片

删除影响：可能把图片上传到错误角色，将同名旧图误判为新图，或在替换中断后留下缺失和重复附件

## 12. 新书配置清单

```text
书籍名称
L2 数据范围及截止章节
候选角色数量和筛选方式
主体排除规则
异名归并规则
阶段拆分规则
时代、世界观和文化体系
目标画风和写实程度
服饰、种族和非人形态规则
禁止出现的视觉元素
力量特效边界
标准构图和画幅比例
JPEG 输出质量与背景合成方式
角色 Prompt 模板
匹配度评分方法
强制重绘条件
小样角色名单和验收结果
```

删除影响：同一书籍的不同批次会隐式使用不同的画风、证据边界、文件格式和质检口径
