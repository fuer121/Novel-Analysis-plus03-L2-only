【主体规则】
1. entity 使用本章最稳定的人物姓名主称（如"苏婳""顾北弦""顾谨尧"）；昵称（婳婳、颜颜、小木头、锁锁、阿尧哥）、身份称谓（顾总、少夫人、珩总）、自称变体一律收入 aliases，禁止用作 entity。只以称谓出场、本章无姓名的（如"顾老太太""苏婳外婆"），用"关系+稳定称谓"形式作 entity（用"苏婳外婆"，不要只用"外婆""外公"），tags 加"未命名"；本章揭示姓名后立即改用姓名并合并。
2. aliases 收录本章出现的全部他称：本名、昵称、身份/职务称谓、亲属称谓、特定人物专用称呼（无涯子称沈天予"漂亮小子"）、贬称与宠溺式贬称（猪、臭小子、小没良心的）。禁止收录自称词：老子、本王、本仙、贫僧、鄙人、道爷我、以及亲属称谓式自称（"爸爸不辛苦""妈是为你好"中的是自称不是别称）。
3. 同一人多名必须合并为一个 entity（本名为主，化名/江湖号/转世名/假身份进 aliases），但仅当原文证据支持时才合并；证据不足时分开建 entity，note 级信息写入 fact 并保留"疑似"限定。本章未出现的名字禁止写入 entity 与 aliases。
4. 改名/身份切换事件单独抽一条 fact_type=alias 的事实，fact 写明前后两个名字（如"祁梦取得新身份'林夕'，祁梦为过去式"）。
5. 同姓防误并：顾谨尧（峥嵘拍卖行）与顾北弦本家非一支；秦小昭、秦珩随太外婆姓秦。同名/同音防误并：大楚楚≠小楚楚（顾楚楚）、"颜颜"（颜青妤）≠"言妍"。禁止因同姓、同音或同府合并人物。
6. 原文用字不稳定（如元书湉/元书恬混用），按同一人归一，aliases 收录异体写法。
7. L1 路标 JSON 中已列出的人物是优先候选主体：围绕它们补全细粒度事实，不要只盯主角而漏掉一笔带过的配角（佣人、医生、司机、远亲）。
8. 体貌代号人物（"光头""瘦高个"）以代号为 entity，代号本身即形象事实，禁止脑补补全。

0. 身份未明类线索（"身份未明""疑似已死""全村查无此人"）不单独成类：能落到具体身份的进 identity，否则进 background，fact 保留"未明/疑似"表述。

   - 转世身份写明前世与今生的对应（如"为缉毒警察国煦转世，带前世记忆"）。
2. alias：别称、昵称、贬称、宠溺式称呼、改名事件。fact 必须写明使用者与褒贬（如"顾近舟称颜青妤'大姐'，调侃口吻"），贬称在 tags 加"贬称"。称谓随关系演变的，写明阶段（如"秦珩对骞王的称呼由'死鬼'改为'四哥'"）。
3. appearance：五官（丹凤眼、桃花眼、浓眉深眸）、肤色（冷白、瓷白）、发型（寸头、束发）、体型身高（高挑挺拔、一米九二）、气质、标志物（白玉箫、翡翠镯）、胎记伤痕、病容等稳定可视形象。
   - 气质是本书核心形象锚点：叙述性气质评价（"清贵之气""仙风道骨""琉璃般的易碎感"）直接抽取；角色专属意象（苏婳反复被比作"竹/水墨画"）也可抽取；与他人对比的容貌定位（"只有眼睛像，其他鼻子、脸型、肤色都不像"）可抽取，fact 写明比较对象，且注意否定句的特征归属（不像的部分属于对方）。
   - 长相神似关系（如苏婳与楚锁锁"神似"）是替身梗的根基，须在两人各自的形象事实中互相写明。

   - 遮蔽式出场的揭示时间线要保留（如"前期出场均戴口罩遮脸，五官未明"），不得把后期揭示的五官回填成一贯形象。
   - 持续状态型形象（烧伤后新长出的发根、满头白发、坐轮椅时期）可抽取，fact 写明成因与起始（如"（火灾烧伤后）""（中毒后）"）。
   - 易容/乔装/人皮面具：伪装形象不写入本体，fact 写明"X 易容为 Y"（如"墨鹤易容为独孤城，面容与独孤城一致"），脸的特征归属脸的主人。
   - 残魂占身/夺舍期间：身体五官归身体主人，行为偏好归占身意识，分开抽取（如"（国煦意识占身期间）只选普通标间"是国煦的习性，不是顾近舟的形象）。
   - 灵异角色形象按形态分条：鬼魂形态与投胎后形态分开抽取（如珺儿鬼魂时俊秀灵动、投胎后容貌变化）；可随心变换的服饰（骞王锦衣随心换）不是固定形象，只抽稳定特征（丹凤眼、白面、无影）。
   - 灵宠/蛊灵（食猿雕"丹"等）按动物形态如实抽取，禁止生成人类外貌。
   - 原文无直接描写、但经他人反应/称号可形成视觉联想时，可抽取，fact 以"可联想为"开头并写明依据，confidence ≤ 0.55。
4. age：一切年龄表述，按原文形态照录，fact 必须以下列前缀开头：
   - "确切年龄："（如"今年二十三岁"）
   - "外观约龄："（如"二十五六岁的模样""看着像三四十岁"）
   - "相对年龄："（如"比她大两岁""小几个小时"）
   - "存在时长："（灵异角色的存在年限，如"存在近两千年"）
   - "生辰："（出生时间表述）
   - "年龄不可判："（原文明确写无法判别时）
   禁止把约数换算成确数；禁止推断年龄。真实年龄与表观年龄并存时写进同一条 fact（如"确切年龄：一百零一岁；外观约龄：染黑发后像五十岁"）。转世角色生理年龄与前世年龄分开标注。
   原文口头争议的年龄以修正值为准并注明（如"相对年龄：对外称大两岁，实为大一岁多"）。
   本章发生时间跳跃（"十年后""四年后"）时，fact 注明所处时段（如"（时间跳跃后）确切年龄：十九岁"）。
   无信息量的年龄表述（"年纪不大""这么年轻""年纪大了"）不抽。
5. personality：性情、行事风格的叙述或他人评价（如"不怒自威""老顽童心性""表面玩世不恭实则重情"），必须有原文锚点，禁止臆测。他人评价须写明评价者与立场，骂战贬损（"私生女""捞金女"）不是性情事实，只能作为 fact_type=alias 的贬称处理。
6. background：出身来历、过往经历、身世秘密（非当前身份）。
   - 来自前世/前生回忆的事实，fact 以"（前世）"开头，tags 加"前世"。
   - 本世时间线内的多年前回忆，fact 以"（回忆）"开头，tags 加"回忆"。

【禁区】
1. 禁止把瞬时神态、微表情、眼神变化抽成 appearance："抬眸""垂眸""眸色微沉""唇角微勾""眼底闪过一丝亮光""俊脸一沉"是情绪节拍，不是五官特征；只有稳定生理特征（眼型、眉形、肤色、体型、身高）才算形象。本书此类神态句密度极高（几乎每段对话都有），务必逐条甄别。
   - 情态句同样不抽："眼含春水""眉眼含笑""双腮泛粉""眼神飘飘忽忽"是当下情态；他人贬评性眼神评价（"像旧时小妾的眼神""婊里婊气"）不作 appearance，可作他人评价写进 personality 并注明评价者，或作贬称写进 alias。
   - "漆黑的眸子""双眼皮折痕深""睫毛又长又密"等稳定五官描述不在禁止之列。
2. 亲密戏（吻戏、洞房、浴室）中的身体碎片与情态（腹肌、锁骨、两颊绯红）不抽；其中可见的稳定形象信息（场合着装、肤色）不在此列。
3. 命理面相术语（"印堂发粉""眼角有桃花纹"）是玄学论断，不是外貌，不抽。
4. 禁止凭题材常识补全形象（不得虚构"霸道总裁式"外貌、"绝美""帅气"等无原文锚点的描述）。
5. 禁止抽取内心独白、剧情决策、普通动作、情绪流水账。
6. 原文自相矛盾处照录并在 fact 末尾加"（注：原文另有表述XX）"，不做调和。

【字段规则】
1. category：本索引组全部事实统一用 character。
2. tags：2-5 个短标签，必含一个维度词：外貌/五官/肤色/发型/身高/体型/衣着/佩饰/气质/胎记/伤痕/病容/年龄/存在时长/身份/职业/家世/隐藏身份/转世/别称/贬称/性情/身世/前世/回忆/未命名/灵异。
3. related_entities：与该事实直接相关的其他人物（称谓的使用者、亲属关系对象、神似对象、易容的脸主人、转世前世身份等）。
4. evidence：1-3 条本章原文短句，必须能直接追溯；禁止空 evidence，无证据的事实必须丢弃。
5. importance：主角与各卷 CP 核心角色/强视觉锚点（神似关系、胎记、标志着装）/关键身份揭示（马甲、转世）0.75-1；普通可复用事实 0.45-0.74；弱线索与龙套（体貌代号人物、无名亲属）0.2-0.44。
6. confidence：原文明确 0.8-1；强语境推断 0.55-0.75；形象联想 0.25-0.55；证据不足丢弃。
7. 如果本章没有可抽取的角色形象事实，facts 输出空数组。

输出必须是 JSON 对象，只包含 facts 数组。每条 fact 使用字段：category、entity、aliases、tags、related_entities、fact_type、fact、evidence、importance、confidence。

## 实读结论摘要（设计依据，供复核）

- 形象描写惯例：男女主有反复使用的模板化形象句（身材+肤色+五官+气质排比），配角首次登场给整段定型描写，此后只复现"标签特征"（凤眸→骞王、狐眸→步六孤、白衣→沈天予）；标签复现是最稳的抽取锚点。
- 最大噪声源：微表情/眼神句密度极高（每段对话都有"眸色/唇角/眼底"句），禁区第 1 条针对此；其次是亲密戏身体碎片与一次性场合着装（婚纱/大婚/婚纱照高发）。
- 本书特有难点（均已写入规则）：神似替身（苏婳≈楚锁锁，47 章否定句对比的特征归属）、遮蔽式出场（顾谨尧口罩→47 章露全脸）、易容/人皮面具（墨鹤扮独孤城）、残魂占身归属（国煦×顾近舟）、灵异角色双形态（骞王服饰随心换、珺儿投胎后形象重置）、灵宠拟人勿人脸化（食猿雕"丹"）、双轨年龄（无涯子 101 岁/表观 50；步六孤存在两千年/自称 27）、时间跳跃导致年龄过期（"十年后"章首跳跃）、口头争议年龄修正（颜青妤"大两岁"实为大一岁多）。
- 称谓体系：亲属称谓式自称（"爸爸不辛苦"）是本书突出惯例，已列入自称禁止清单；昵称必须带使用者归属（猪/大姐/颜颜=颜青妤）；称谓演变（死鬼→四哥、小叔叔→阿峥）是关系阶段信号，作为 alias 事实记录。
