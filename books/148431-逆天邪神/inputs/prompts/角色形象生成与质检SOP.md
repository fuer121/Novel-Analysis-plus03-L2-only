# 小说角色形象生成与质检 SOP

## 1. 方法目标

这套方法用于把小说中的角色事实索引转换为可追溯、可生图、可审核、可迭代的角色形象库

核心产物包含：角色结构化资料、原文证据、分阶段形象、生图提示词、形象图、匹配度评分和重绘记录

方法不追求把索引中的每个名称都画出来，而是优先建立一个有明确证据、角色身份稳定、视觉特征可分辨的角色集合

## 2. 总体流程

```text
L2 角色事实索引
  ↓
角色候选排名与主体过滤
  ↓
同人异名归并
  ↓
年龄和时期阶段拆分
  ↓
结构化形象与原文证据
  ↓
年龄一致性与气质一致性检查
  ↓
生图提示词转写
  ↓
GPT Image 2 批量生图
  ↓
文件与画幅基础校验
  ↓
逐图对照原文质检与匹配度评分
  ↓
明显不符合角色重绘
  ↓
重绘后再验收
  ↓
写入多维表格并读回验证
```

每一层都必须有可验证的输入和输出，不允许从角色名直接跳到生图

## 3. 角色筛选与归并

### 3.1 候选排名

默认按角色在目标 L2 索引组中的事实数排名，作为重要性和可复用价值的粗筛

候选数量是主体数，不是最终图片数，因为同一角色可能拆分为幼年、少年、成年或特定形态

### 3.2 排除规则

下列主体默认不进入人物立绘队列：

- 组织、宗门、家族、队伍和群体
- 修炼境界、功法、法宝和其他物品
- 只有泛称且不可稳定识别的未命名主体
- 无法确定指向单一人物的历任称号
- 被模型错误抽取成人物的种族、血脉、能力或地名

非人主体不等于应被排除，如果龙神、魂灵、神瞳或其他非人存在是稳定角色，应保留并按原文形态生成

### 3.3 同人异名归并

只合并有明确同人证据的名称：

- 本名与旧名
- 明确的改名记录
- 唯一且稳定的专属称号
- 原文明确说明指向同一人的暂称

不得因为称号相似、能力相似或根据题材常识强行合并

## 4. 角色阶段拆分

仅在下列条件同时成立时拆分角色阶段：

1. 原文明确给出年龄、时期或成长节点
2. 不同阶段存在稳定的外形、体型、着装或气质差异
3. 每个阶段都有独立可追溯的原文证据

命名采用「角色-幼年」「角色-少年」「角色-成年」或「角色-特定形态」

临时战损、易容、换装、情绪变化、短暂力量异变不作为阶段拆分依据

不得把少年时期的脸部、成年时期的身材和后期战损服饰混合成一个不存在的形象

## 5. 结构化字段规则

每条角色形象记录至少包含：

| 字段 | 规则 |
| --- | --- |
| 书籍名称 | 稳定作品名 |
| 角色名称 | 合并后主称，分阶段时加后缀 |
| 别称 | 只收录可追溯且指向明确的别名、称谓和旧名 |
| 性别 | 优先使用原文明确表述，无证据填「未知」 |
| 年龄 | 保留原文形态，不把约数换算为确数，不用修为反推年龄 |
| 形象描述 | 优先稳定脸部、发色、瞳色、体型、着装、标志和气质 |
| 原文证据 | 带章节号保留可逐字回查的原文短句 |
| 生图提示词 | 由形象描述转写，不增加无证据属性 |
| 形象图 | 最终验收版图片 |
| 匹配度 | 对当前最终图片进行 0–100 分估算 |

## 6. 年龄与气质一致性

### 6.1 年龄硬检查

生图前必须检查形象描述和提示词是否与年龄证据一致

- 幼年和少年角色不得使用成年身材、成熟礼服或性感化描述
- 中年和年长角色不得统一生成二十岁青年脸
- 长寿种族应区分真实寿命和原文外观约龄
- 原文无年龄证据时不擅自填写具体年龄

检查结果应作为生图准入条件，年龄存在未解决冲突的记录不进入批量生图

### 6.2 气质硬检查

气质只能来自原文的稳定描述、他人稳定评价或反复出现的视觉感受

常见气质维度包括清冷、娴静、妖异、威严、纯净、沉稳、阴鸷、英武、虚弱、稚嫩和沧桑

无表情不等于无气质，气质应通过脸型、眉眼、骨相、姿态重心、服饰轮廓、材质和色彩体现，不应靠夸张表情或剧情动作表现

## 7. 男女骨相与角色差异化

角色库不能只做「换发色和换衣服」，脸部骨相和体态必须根据角色设定区分

### 7.1 性别差异

当原文性别明确时，提示词应明确约束：

- 男性角色根据年龄体现更清晰的眉骨、下颌、面部宽窄、肩颈比例和体格差异
- 女性角色根据年龄与气质区分稚嫩、娴静、冷艳、丰润、高挑、威严或英武，不使用统一锐脸大眼模板
- 性别未知时可使用中性完整五官，但不得生成无脸人

### 7.2 角色个体差异

每个提示词至少应有两类个体锚点：

1. 一项脸部或骨相锚点，如宽阔下颌、细长冷眸、深陷老目、少年圆润脸部或刚毅立体轮廓
2. 一项形象或气质锚点，如眉心火焰印记、赤鳞、冰蓝长发、威临感、稚嫩感或枯瘦体态

无原文证据的发色、瞳色、龙角、尾巴、翅膀、武器、冠冕和大面积装甲不得作为默认补全

## 8. 画风与构图基线

默认图片规格：

- 古风玄幻世界观
- 精致国漫角色设定立绘
- 二维或半厚涂国漫审美
- 非写实、非照片写实
- 非现代时装、非现代发型、非现代配饰
- 服饰轮廓、纹样和材质符合东方玄幻
- 单一角色或单一非人主体
- 纯白背景
- 完整全身，头顶、双脚不裁切
- 无表情、无剧情动作
- 自然站立，双手垂放在大腿两侧
- 画幅比例 3:4
- 画面中无角色名、年龄、水印或其他文字

非人主体不强制使用人类站姿，应优先保留原文形态，如巨大眼瞳、龙躯、凤凰火环或魂灵本体

## 9. 生图提示词模板

```text
【角色与阶段】
{character_name}，{gender}，年龄或外观约龄：{age}

【脸部与骨相】
{face_shape}，{brow_and_eyes}，{age_features}，体现明确的{gender_or_neutral}骨相，避免与其他角色共脸

【体态与服饰】
{body_shape}，{clothing}，{materials_and_patterns}

【标志特征】
{distinctive_features}

【气质】
整体呈现{temperament}，通过骨相、服饰轮廓和材质表现，不使用夸张表情或动作

【画面规格】
古风玄幻世界观，精致国漫角色设定立绘，二维或半厚涂国漫审美，非写实，非现代，单一主体，纯白背景，全身完整入画，无表情，无肢体动作，自然站立，双手垂放在大腿两侧，画幅比例 3:4，画面无文字

【证据边界】
严格遵循上述年龄、性别、外貌和气质，不添加原文未提及的发色、瞳色、服饰、武器、角、翅膀、尾巴或额外装饰
```

不建议对所有角色使用一段只替换姓名的模板，模板用于约束画风和构图，角色骨相、体态、服饰和气质必须使用每人独立内容

## 10. 生图执行规则

### 10.1 小样本先行

批量生图前先选择代表性角色测试：

- 少年男性
- 成年男性
- 幼年女性
- 成年女性
- 年长角色
- 非人主体

样图必须先检查画风、古代服饰、男女骨相、年龄和构图，通过后才允许全量执行

这一步是防止「提示词结构正确，但整批图片都偏现代或偏写实」的关键门槛

### 10.2 批量与断点

- 使用 JSONL 或等价结构保存每个生图任务
- 每条任务必须有稳定 ID、角色名、提示词和目标文件名
- 支持断点续跑，已成功且文件存在的任务不重复执行
- 分批执行时使用互不重叠的范围和独立结果日志
- 限额或连接失败时及时停止无效重试，保留断点和失败原因
- 不在日志、清单或最终报告中输出 API Key

### 10.3 文件规则

建议文件名格式：

```text
{global_index:03d}_{character_name}.png
```

正式图片、旧版图片、重绘候选图和流式中间图必须分目录存放，不得只依靠同名覆盖来区分版本

## 11. 生图后质检

质检必须真实查看图片，不得根据提示词推定图片已经符合

### 11.1 基础文件检查

- 目标记录数与正式图片数一致
- 文件为可解码的正式 PNG
- 图片非空白、非全透明
- 画幅为 3:4 或允许的极小误差
- 不存在遗留 partial 文件被当作正式图
- 不同角色的图片哈希不完全相同

### 11.2 视觉检查维度

| 维度 | 关键问题 |
| --- | --- |
| 主体 | 是否只有一个目标角色，是否出现重复人物或多人拼图 |
| 性别 | 是否出现男性女相、女性男相或未知性别无脸化 |
| 年龄 | 是否符合幼年、少年、青年、中年、年长或特定外观约龄 |
| 脸部 | 是否存在无脸、裁脸、共脸、骨相错误或过度统一的美型模板 |
| 体态 | 娇小、高大、枯瘦、丰润、英武或虚弱是否符合原文 |
| 服饰 | 是否现代化、西式骑士化、无证据性感化或过度帝王化 |
| 气质 | 清冷、威严、妖异、稚嫩、沉稳、英武等是否与证据一致 |
| 标志 | 原文明确的发色、瞳色、印记、伤痕、鳞片或服饰是否保留 |
| 形态 | 非人角色是否被错误拟人，人形角色是否被无证据龙化或精灵化 |
| 构图 | 是否全身完整、白底、无文字、无动作、无头脚裁切 |

### 11.3 建议检查方式

1. 先生成带编号和角色名的低分辨率联系表，用于快速发现共脸、男女趋同和风格漂移
2. 对疑似异常项单独查看高清原图
3. 结合角色结构化资料和原文证据评分
4. 重绘后再做一次验收，不得把「已重新生成」等同于「已修复」

## 12. 匹配度评分规则

匹配度是对当前最终图片的人工估分，不是模型置信度

### 12.1 评分维度

| 维度 | 分值 |
| --- | ---: |
| 年龄与人生阶段 | 20 |
| 性别、脸部骨相与体态 | 20 |
| 发色、瞳色、标志特征 | 20 |
| 服饰、时代和世界观 | 15 |
| 角色气质 | 15 |
| 立绘构图和可用性 | 10 |

### 12.2 分数解释

| 分数 | 结论 |
| --- | --- |
| 90–100 | 高度匹配，关键属性和气质均可追溯，可直接作为正式形象 |
| 80–89 | 总体匹配，存在轻微模型补全或次要特征偏差，通常可接受 |
| 70–79 | 基本可用，原文证据较少或存在可见偏差，建议保留复审标记 |
| 60–69 | 明显偏差，应重绘 |
| 0–59 | 核心设定或画面形态错误，必须重绘 |

即使总分高于 70，只要出现以下硬错也必须重绘：

- 性别错误
- 幼年、少年或成年阶段错误
- 非人主体形态错误
- 无脸、裁脸或主体严重裁切
- 一张立绘出现多个同一角色或无关人物
- 明显现代服饰或与作品不符的西式风格
- 存在角色名、年龄或水印文字
- 与原文关键标志特征相反

## 13. 重绘方法

重绘提示词不应只增加「请修正」，而应针对可见问题改写为正向约束

| 问题 | 重绘方向 |
| --- | --- |
| 男性女相 | 明确年龄层、男性眉骨、下颌、肩颈比例、体格和原文气质 |
| 女性模板化 | 明确脸型、眉眼、年龄感、体态和角色特有气质 |
| 年龄偏差 | 明确外观约龄和年龄可见特征，去除矛盾阶段描述 |
| 无脸 | 明确完整可见的五官、脸部不遮挡、不空白、不裁切 |
| 多人或多阶段 | 明确画面只有一个主体，只保留目标阶段 |
| 现代或西式风格 | 明确东方古风玄幻轮廓、材质、纹样、发式和鞋履 |
| 无证据性感化 | 明确服饰完整、端庄，删除露肩、高开衩、现代礼服或高跟鞋等无证据元素 |
| 非人误拟人 | 删除人体结构，明确眼瞳、龙躯、凤凰火环或其他原文本体 |
| 战损污染稳定形象 | 去除临时血污、断肢、衣物破损和情绪动作，恢复稳定常态 |

重绘完成后必须再次评分，并使用重绘后分数覆盖当前展示分数

## 14. 多维表格交付规则

建议多维表格字段：

1. 书籍名称
2. 角色名称
3. 别称
4. 性别
5. 年龄
6. 形象描述
7. 原文证据
8. 用于 GPT Image 2 生图的提示词
9. 形象图
10. 角色形象和原文匹配度

写入规则：

- 文本记录可批量创建或更新，单批不超过平台上限
- 附件必须使用附件专用上传命令，不得当作普通文本值写入
- 角色序号、角色名、本地文件名和远端 record_id 必须保存稳定映射
- 附件操作以返回退出状态和读回结果为准，不根据 CLI 前置进度文本误判成功或失败
- 重绘替换附件时不能只比较文件名，因为旧图与新图可能同名，应同时比较文件大小或哈希
- 删除旧附件后必须立即上传新附件并读回，过程中止时要能发现并恢复缺失记录
- CLI 如果限制本地文件路径，应使用工作目录内的相对路径，不盲目重试被拒绝的绝对路径

最终读回必须确认：

- 记录数与目标数一致
- 每条记录恰好一个形象图附件
- 附件缺失数为 0
- 附件重复数为 0
- 本地文件名与远端文件名一致
- 重绘记录的远端附件大小或哈希与本地新版一致
- 匹配度无缺失且与最终评审数据一致

## 15. 异常处理

### 15.1 生图安全审核拦截

涉及幼年或少年角色时，提示词必须强化非性化、服饰完整、端庄和角色设定立绘语义

如果上游连续返回空图或审核拦截，可做等义安全改写，但必须保留角色年龄感、关键服饰和原文标志，不得通过把幼年角色改成成年角色来规避审核

### 15.2 网关超时和空图

- 优先启用流式返回和 partial image
- 使用有限次数重试和逐次退避
- 连续失败时记录任务 ID、错误类型和已尝试次数
- 仅重跑失败项，不重跑已成功全批

### 15.3 服务额度耗尽

确认为硬额度错误后应立即停止剩余进程，保留已生成图片和断点日志，不应继续将所有待处理项刷成失败

### 15.4 风格全局错误

如果小样本或已生成图片大面积出现现代服饰、写实人像或与作品不符的审美，应将这批图片整体隔离为无效版本，修正全局提示词后重新生成

不应通过对每张图局部打补丁来修复一个全局风格基线错误

## 17. 《逆天邪神》实践基线

本次实践从角色形象 L2 索引中按事实量筛选前 300 个角色主体，对 6 个有明确成长阶段的角色进行拆分，最终形成 307 条形象记录

第一轮逐图复核的平均匹配度为 78.15，其中 72 张因为明显偏差或硬错进入重绘，重绘和替换后最终平均匹配度为 85.99

本次最有价值的调整不是提高画面装饰度，而是：

1. 把古风玄幻、国漫、非写实、非现代写成全局硬约束
2. 把年龄和气质一致性设为生图前准入条件
3. 对有明确成长差异的角色拆分人生阶段
