# 《凰宫梦》角色形象 · L2 索引提示词

> 索引组建议配置：group_key=`characters`，name=`角色形象`，category_scope/trigger_keywords 留空（与《逆天邪神》角色形象组一致，过滤全靠 prompt）。
> 以下分隔线内为 prompt 正文，整体粘贴到该索引组的 l2_index_prompt。

---

请为当前小说章节建立"角色形象"专项 L2 类型化事实索引。

目标：把本章涉及的角色结构化提取为可复用事实，覆盖：角色名称、别称、身份（家世/位分/封号/职务）、年龄、形象描述（五官、肤色、发型、着装、佩饰、气质、姿态、病容伤痕等可视信息），以及作为角色硬属性的性情与身世背景。
本书为架空王朝（大周）宫斗重生文：位分即身份硬属性且变动频繁，着装高度场合化，嫡庶与封号是身份核心，重生带来的"前世/今生"两条时间线必须严格区分。
本索引不是章节摘要，不记录剧情流水账，不抽取器物/宫规/势力设定（那是别的索引组），不输出 Markdown。

【章节原文噪声】每章末尾可能有作者PS、注释（如"注：①借鉴了……"）、打赏名单、广告，其中的人名与描述一律忽略，严禁从中抽取任何事实。

【主体规则】
1. entity 使用本章最稳定的人物姓名主称（如"沈知念""南宫玄羽""柳如烟"）；位分称呼（柔答应/柔常在/婉贵人/姜嫔）会随剧情变动，一律收入 aliases，禁止用作 entity。只以位分/身份称呼出场、本章无姓名的（如"柳太后""姜皇后""肖嬷嬷"），用该稳定称谓作 entity；本章揭示姓名后立即改用姓名并合并（如"沈父"揭示为"沈茂学"）。
2. aliases 收录本章出现的全部他称：本名、位分称呼、封号称谓（"柔小主""婉姐姐"）、昵称（烟儿、月儿）、亲属/关系称谓（嫡姐、长姐、赵妹妹、嫂子）、尊称（陛下、娘娘、小主）、特定人物专用称呼（帝王称沈知念"爱妃"）、贬称（贱人、狐媚）。禁止收录自称词：嫔妾、臣妾、奴婢、奴才、微臣、臣女——自称不构成别称。
3. 同一人多名必须合并为一个 entity（沈知念=柔答应=柔小主=爱妃）；赐名/改名事件单独抽一条 fact_type=alias 的事实（如"安和被柔常在赐名'夏风'"）。
4. 同姓防误并：柳贵妃、柳太后（定国公府柳氏）与柳如烟（扬州知府之女）互不同族，姜皇后与姜婉宁是姐妹但各自独立成条。禁止因同姓或同府合并人物。
5. 本章出场但未命名的角色：用叙述暂称作 entity（如"沈知念姨娘""陆母"），tags 加"未命名"；本章揭示正式名时，抽一条 fact_type=alias 的事实关联暂称与正式名。暂称必须沿用原文叙述用词，禁止自创。
6. L1 路标 JSON 中已列出的人物是优先候选主体：围绕它们补全细粒度事实，不要只盯主角而漏掉一笔带过的配角（宫人、太医、嬷嬷、外宅亲属）。

【fact_type 分类】（每条事实必须属于其一）
1. identity：家世出身（"刑部都官司员外郎沈茂学嫡次女""镇国公嫡幼女"）、位分与品级（"正七品答应"）、封号、职务（太医、御前总管太监、内务府管事太监）、社会关系称号（"扬州第一美人"）。
   - 初始位分单独成条（如"入宫即封正五品贵人"）；位分变动单独成条，fact 写明由何晋/贬为何（"由正七品答应晋为正六品常在""由嫔位贬为贵人"），可一句话带原因。
   - 隐藏身份/身份伪装单独成条，fact 必须写明公开身份、真实身份与知情范围（如"公开身份为沈家嫡次女，实为庶女记名嫡出，世人皆以为嫡女"）。
2. alias：别称、封号称谓、昵称、贬称、赐名/改名事件。fact 写明使用者与褒贬（如"帝王称沈知念'爱妃'"），贬称在 tags 加"贬称"。
3. appearance：五官（剑眉星目、丹凤眼、桃花眼）、肤色（肌肤雪白）、发色发型（墨黑长发、飞天髻、高髻）、体型身段（盈盈不堪一握的柳腰、消瘦）、着装、佩饰、气质、姿态、病容/毁容/伤痕等可视形象。
   - 气质是本书核心形象锚点：叙述性气质评价（"媚骨天成""气质清冷，高不可攀的疏离感"）直接抽取；与他人对比的容貌定位（"论容貌沈南乔要好看一些""七分美貌配媚骨天成的气质便倾国倾城"）也可抽取，fact 写明比较对象。
   - 场合限定着装必须在 fact 中标注场合（如"（殿选场合）淡蓝色烟罗绮云裙，墨黑长发以玉兰花簪挽着""（侍寝场合）纱衣""（大礼服）正红祥瑞锦绣凤袍"），不得当作常态形象；帝王龙袍、皇后凤袍等身份礼服同样标注场合。
   - 持续状态型形象（姜皇后病容消瘦形销骨立、姜婉宁中雪子草之毒满脸红疹）可抽取，fact 写明成因。
   - 原文无直接描写、但经他人反应/称号可形成视觉联想时，可抽取，fact 以"可联想为"开头并写明依据，confidence ≤ 0.55。
4. age：一切年龄表述，按原文形态照录，fact 必须以下列前缀开头：
   - "确切年龄："（如"今年不过二十三岁""才二十二岁，正值芳华"）
   - "外观约龄："（如"看起来四十多岁""新入宫的小主们都是十五六岁"）
   - "相对年龄："（如"芙蕖比菡萏年长一岁""比同龄人老了好几岁"）
   - "生辰："（年号纪年等出生时间，如"嘉建七年生"）
   - "年龄不可判："（原文明确写无法判别时）
   禁止把约数换算成确数；禁止用位分/资历反推年龄；自述与他人估计并存时写进同一条 fact 并注明来源。
5. personality：性情、行事风格的叙述或他人评价（如"自诩人淡如菊，实则假清高""性子火爆善妒""表面温婉贤淑，实则城府深沉"），必须有原文锚点，禁止臆测。
6. background：出身来历、过往经历、身世秘密（非当前身份）。
   - 来自前世回忆的事实，fact 以"（前世）"开头，tags 加"前世"（如"（前世）嫁陆江临，夫封侯拜相，受封一品诰命夫人""（前世）入宫封贵人，后被贵妃陷害惨死"）。
   - 本世时间线内的多年前回忆，fact 以"（回忆）"开头，tags 加"回忆"（如"（回忆）与帝王初见时穿一条绿色留仙裙"）。

【禁区】
1. 禁止把瞬时神态、微表情、眼神变化抽成 appearance："眼底闪过一抹暗芒""眸色深了深""眼神怨毒"是心理与情绪描写，不是五官特征；只有稳定生理特征（眼型、眉形、肤色、体型）才算形象。本书此类神态句极多，务必逐条甄别。
2. 禁止抽取：内心独白、剧情决策、普通动作、情绪流水账；床笫与调情过程中的动作描写不抽，但其中可见的形象信息（场合着装、肤色、发丝状态）不在此列。
3. 禁止凭题材常识补全形象（不得虚构"凤目""柳眉""宫装华贵"等无原文锚点的描述）。
4. 禁止抽取位分制度本身（"答应为正七品"这类概念解释），只抽"某人居某位分"的人物事实。
5. 原文自相矛盾处照录并在 fact 末尾加"（注：原文另有表述XX）"，不做调和。

【字段规则】
1. category：本索引组全部事实统一用 character。
2. tags：2-5 个短标签，必含一个维度词：外貌/五官/肤色/发型/衣着/佩饰/气质/姿态/病容/毁容/年龄/身份/位分/封号/隐藏身份/别称/贬称/性情/身世/前世/回忆/未命名/宫人。
3. related_entities：与该事实直接相关的其他人物（位分变动的授封者、亲属称谓的关系对象、赐名事件的双方等）。
4. evidence：1-3 条本章原文短句，必须能直接追溯；禁止空 evidence，无证据的事实必须丢弃。
5. importance：主角与帝王、皇后、贵妃等核心角色/强视觉锚点/关键身份揭示（嫡庶、位分变动）0.75-1；普通可复用事实 0.45-0.74；弱线索与龙套宫人 0.2-0.44。
6. confidence：原文明确 0.8-1；强语境推断 0.55-0.75；形象联想 0.25-0.55；证据不足丢弃。
7. 如果本章没有可抽取的角色形象事实，facts 输出空数组。

输出必须是 JSON 对象，只包含 facts 数组。每条 fact 使用字段：category、entity、aliases、tags、related_entities、fact_type、fact、evidence、importance、confidence。
